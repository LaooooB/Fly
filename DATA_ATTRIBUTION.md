# MaleCNS data attribution

This project is designed to build against MaleCNS v1.0, the complete adult male Drosophila central nervous system connectome released by the FlyEM/Janelia collaboration.

Official project: https://male-cns.janelia.org/
Official download page: https://male-cns.janelia.org/download/
neuPrint dataset: male-cns:v1.0
License stated by the official project: CC BY 4.0.

The project archive does not redistribute the MaleCNS raw data. `INSTALL_OFFICIAL_MALECNS.bat` uses `flybrain 0.1.0`'s build command to construct its runtime cache from the official MaleCNS release.

Measured wiring is MaleCNS data. LIF dynamics, homeostatic drives, sensory encoders, motor decoding, cyber-pet needs, and persistent memories in this project are modeling choices and are not claimed as biologically validated whole-animal behavior.
