# MaleCNS 赛博宠物 v0.7

Windows 本地 2D 赛博宠物。

- 多人共享同一套训练数据
- 饥饿 100% 后开始 60 秒死亡倒计时
- 濒死时负反馈持续增强
- 饿死会给共享模型终局重罚
- 吃到面包恢复 15% 饱食度，并清除饿死倒计时
- 新增“游戏机”
- 玩游戏不恢复饱食度
- 玩游戏会提高心情并产生强多巴胺正反馈
- 越接近饿死，食物感知越强，游戏吸引力越弱
- 死亡人物停止行动和训练
- 模拟速度 1×–8×

## 放置物品

右侧物品搜索支持：

```text
面包
游戏机
```

选择后点击“放置”，再点击地面。

## 生存规则

```text
饥饿 < 100%   正常
饥饿 = 100%   开始 60 秒倒计时
60 秒内吃面包  倒计时清零
60 秒未进食    死亡
```

死亡是共享训练池的强负反馈。

## 更新

```text
UPDATE.bat
```

然后：

```text
RUN_FLY.bat
```

不用重新下载 MaleCNS 数据。
