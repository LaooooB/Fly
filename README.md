# MaleCNS 赛博宠物 v0.9

- 支持中文行为指令输入框
- 默认对当前选中人物下达指令
- 支持“所有人 去吃面包”这类全体指令
- 指令不会瞬移或直接改坐标，只会改变当前行为目标和动作偏置
- 生存、剧痛、临墙危险优先级高于娱乐/繁衍类指令
- 指令会进入实时“神经意图”解释，可看到指令影响强度
- 单次目标完成后自动清除；探索持续到取消
- 继续支持连续放置、人口增减、死亡、生存压力、游戏、多巴胺、繁衍和共享训练

## 指令输入

右侧输入框可以直接输入：

```text
吃面包
去吃面包
玩游戏
去找异性
离开墙边
休息
随便走走
取消指令
```

默认作用于当前选中的人物。

全体指令：

```text
所有人 去吃面包
所有人 玩游戏
所有人 取消指令
```

## 指令优先级

```text
濒死 / 剧痛 / 临墙危险
↓
生存
↓
用户指令
↓
繁衍 / 娱乐 / 探索
```

因此“去玩游戏”不会强迫一个快饿死的人继续娱乐。

## 神经意图

示例：

```text
神经意图  进食 68% · 前进
指令 去吃面包 · 影响 74%
```

这里显示的是当前感觉、身体状态、MaleCNS 输出、共享 RL 偏置和用户指令的实时综合解释，不代表真实主观意识。
