# MaleCNS 赛博宠物 v0.6

Windows 本地 2D 赛博宠物。

- 绿色地面
- 可增加男性 / 女性，最多 12 人
- 女性基础移动速度约为男性的 1.3×
- 所有人都能找面包、吃面包、产生奖励/疼痛并参与学习
- 面包只恢复 15% 饱食度
- 所有人共享同一套训练数据和同一个 Q 表
- 人越多，同一模型每轮收到的训练样本越多
- 点击人物切换右侧个体身体数值
- 训练数值显示的是全体共享学习
- 模拟速度可拖拽：1×–8×

## 多人训练

右侧点击：

```text
+ 男
+ 女
```

新增的人有独立的饥饿、疲劳、位置等身体状态。

学习模型只有一份：

```text
J:\FLY\save\pet_state.json
└─ policy_q
```

例如：

```text
1 人 = 1 份环境经验
2 人 = 同一个 Q 表接收 2 个人的经验
4 人 = 同一个 Q 表接收 4 个人的经验
```

不会为每个人生成独立训练模型。

## 放置面包

1. 右侧选择“面包”
2. 点击“放置”
3. 点击地面位置

## 更新

```text
UPDATE.bat
```

然后运行：

```text
RUN_FLY.bat
```

不用重新下载 MaleCNS 数据。
