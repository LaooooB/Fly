# MaleCNS 赛博宠物 v0.4

Windows 本地 2D 赛博宠物。

- 绿色地面
- 一男一女，地面走路动画
- 鼠标悬停人物显示粗描边
- 点击人物切换右侧数值
- 男性学习显示：总量 / 本局 / 近10秒
- 面包只恢复 15% 饱食度
- 面包不会自动生成或补充

## 放置面包

1. 右侧选择“面包”
2. 点击“放置”
3. 点击地面位置

## 运行

首次安装：

```text
INSTALL_OFFICIAL_MALECNS.bat
```

启动：

```text
RUN_FLY.bat
```

以后更新：

```text
UPDATE.bat
```

不用重新下载 MaleCNS 数据。

存档：

```text
J:\FLY\save\
```
