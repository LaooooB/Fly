# MaleCNS 赛博宠物 v0.3

Windows 本地 2D 赛博宠物。人形外观，底层仍使用 MaleCNS v1.0。

## 放置面包

运行后：

1. 点击右侧“物品”
2. 搜索或选择“面包”
3. 点击“放置”
4. 点击场地位置

面包不会自动生成，吃掉后也不会自动补充。

## 第一次安装

建议目录：

```text
J:\FLY\app\
```

首次安装运行：

```text
INSTALL_OFFICIAL_MALECNS.bat
```

启动：

```text
RUN_FLY.bat
```

## 更新

直接运行：

```text
UPDATE.bat
```

不用重新下载 MaleCNS 数据。

存档仍在：

```text
J:\FLY\save\
```

完整技术说明见 [README_CN.md](README_CN.md)。
